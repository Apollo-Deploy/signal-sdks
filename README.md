# Apollo Signal SDKs

Public, generated clients for the Apollo Signal API. This repository contains the SDK source and
its public release-publishing workflow; the private Signal API implementation is not included.

> Release `v1.0.4`, generated by Tesseract `4.0.0` from the published API
> contract. Generated files must not be edited manually.

## Install

| Language or framework | Package | Install |
| --- | --- | --- |
| TypeScript | `@apollo-deploy/signal-sdk` | `npm install @apollo-deploy/signal-sdk@1.0.4` |
| Python | `apollo-deploy-signal-sdk` | `pip install apollo-deploy-signal-sdk==1.0.4` |
| Ruby | `apollo-deploy-signal-sdk` | `gem install apollo-deploy-signal-sdk -v 1.0.4` |
| Rails | `apollo-deploy-signal-sdk-rails` | `gem install apollo-deploy-signal-sdk-rails -v 1.0.4` |
| Go | `github.com/apollo-deploy/signal-sdks/sdks/go/signal` | `go get github.com/apollo-deploy/signal-sdks/sdks/go/signal@v1.0.4` |
| PHP / Laravel | `apollo-deploy/signal-sdk` | `composer require apollo-deploy/signal-sdk:^1.0.4` |
| Java | `com.apollodeploy.signal:signal-sdk-java` | Maven Central version `1.0.4` |
| Kotlin | `com.apollodeploy.signal:signal-sdk-kotlin` | Maven Central version `1.0.4` |
| .NET / C# | `ApolloDeploy.Signal` | `dotnet add package ApolloDeploy.Signal --version 1.0.4` |
| Rust | `apollo-signal-sdk` | `cargo add apollo-signal-sdk@1.0.4` |
| Elixir | `apollo_signal` | `{:apollo_signal, "~> 1.0.4"}` |
| Swift | `ApolloSignal` | `.package(url: "https://github.com/Apollo-Deploy/signal-sdks.git", from: "1.0.4")` |
| Zig | `apollo_signal` | Download the release archive |
| CLI | `@apollo-deploy/signal-cli` | `npm install --global @apollo-deploy/signal-cli@1.0.4` |

Each generated target is under [`sdks/`](./sdks). Package-manager releases are built from the same
tagged source. Checksummed archives are also attached to every GitHub release for inspection and
offline use.

The root `composer.json` publishes the PHP client and its optional Laravel integration as one
Packagist package. Laravel discovers the bundled service provider automatically; plain PHP projects
do not install Illuminate as a runtime dependency.

## Swift Package Manager

The root `Package.swift` exposes `ApolloSignal`, so Swift applications can depend on this repository
without a separate package registry:

```swift
.package(
    url: "https://github.com/Apollo-Deploy/signal-sdks.git",
    from: "1.0.4"
)
```

## Generation provenance

[`generation.json`](./generation.json) records the API release, public-contract checksum, Tesseract
version, and package identities. It deliberately does not contain a private repository URL or source
commit.
