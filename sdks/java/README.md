# Apollo Signal API Java SDK

Java client for the Apollo Signal API API.

> Generated by Tesseract. Generated source files should not be edited manually.

## Installation

```groovy
implementation 'com.apollodeploy.signal.sdk:com.apollodeploy.signal.sdk:1.0.4'
```

## Quick start

```java
import com.apollodeploy.signal.sdk.ApolloSignalApiClient;

var client = new ApolloSignalApiClient(
        new ApolloSignalApiClient.Config()
                .baseUrl("https://signal.apollodeploy.com")
                .timeoutMs(15_000));
var api = client.emails();
```

## Configuration and reliability

The generated transport reuses a `java.net.http.HttpClient`, uses Jackson for JSON, applies bounded operation timeouts, and retries transient failures with exponential backoff and `Retry-After` support. `GET`, `HEAD`, `OPTIONS`, `PUT`, and `DELETE` are retryable by default. Unsafe methods require `retryUnsafeRequests(true)` or a non-empty `Idempotency-Key`/`X-Idempotency-Key` header.

```java
var client = new ApolloSignalApiClient(
        new ApolloSignalApiClient.Config()
                .maxRetries(3)
                .retryUnsafeRequests(false)
                .defaultHeaders(java.util.Map.of("X-Application", "my-service")));
```

SSE operations return a closeable `Transport.SseStream<T>` that implements `Iterable<T>` and also exposes a Java `Stream<T>` through `stream()`.

## Error handling

Operations throw `SdkException` for API and transport failures. It includes the HTTP status, API code, request ID, response headers, and response body when available.
