# Apollo Signal API Ruby SDK

Ruby client for the Apollo Signal API API.

> Generated by [Tesseract](https://www.npmjs.com/package/@apollo-deploy/tesseract). Generated source files should not be edited manually.

## Installation

```ruby
gem 'apollo-deploy-signal-sdk-rails'
```

```bash
bundle install
```

## Quick start

```ruby
require 'apollo-deploy-signal-sdk-rails'

client = ApolloDeploySignalSdkRails::Client.new(
  base_url: "https://api.signal.apollodeploy.com",
  timeout: 15
)

api = client.emails
```

## Configuration and reliability

The transport provides bounded timeouts, exponential-backoff retries, rate-limit handling, default headers, and structured `SDKError` values. Unsafe requests are retried only when explicitly enabled or made idempotent.

```ruby
client = ApolloDeploySignalSdkRails::Client.new(
  timeout: 30,
  retries: {
    attempts: 3,
    backoff: 0.4,
    jitter: true,
    max_backoff: 30.0
  },
  default_headers: { 'X-Application' => 'my-service' }
)
```

## Rails integration

The gem registers `ApolloDeploySignalSdkRails::Railtie`. Configure it from the Rails
application and resolve a fresh client when needed:

```ruby
# config/environments/production.rb
config.apollo_deploy_signal_sdk_rails.base_url = ENV.fetch("apollo_deploy_signal_sdk_rails_BASE_URL")

# application code
client = ApolloDeploySignalSdkRails.rails_client
```

The Railtie applies configuration after Rails configuration initializers load.
