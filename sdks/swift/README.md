## Installation

Add the generated package to your Swift package dependencies or copy it into a workspace. The generated package is version `1.0.5` and has no third-party dependencies.

## Quick start

```swift
import ApolloSignal

let client = try ApolloSignalApi(
    configuration: ClientConfig(
        baseURL: "https://signal.apollodeploy.com"
    )
)
let api = client.emails
```

## Configuration and reliability

The Foundation URLSession transport uses async/await and Codable, applies per-operation or client-level timeouts, bounds request and response bodies, preserves request IDs and structured API error metadata, and retries only transient failures within a bounded limit. Unsafe methods require an idempotency key or explicit `retryUnsafeRequests` configuration before they are retried. `Retry-After` is honored up to the transport delay cap.

```swift
let client = try ApolloSignalApi(
    configuration: ClientConfig(
        timeoutMilliseconds: 30_000,
        maxRetries: 3,
        retryUnsafeRequests: false,
        maxRequestBodyBytes: 5 * 1024 * 1024,
        maxResponseBodyBytes: 5 * 1024 * 1024
    )
)
```

SSE operations return `AsyncThrowingStream` values and decode each JSON event payload into its generated Codable model.
