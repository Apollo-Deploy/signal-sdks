# Apollo Signal API .NET SDK

.NET client for the Apollo Signal API API.

> Generated by Tesseract. Generated source files should not be edited manually.

## Installation

```bash
dotnet add package ApolloDeploy.Signal
```

## Quick start

```csharp
using ApolloDeploySignal;

var client = new ApolloSignalApiClient(new ApolloSignalApiClientConfig
{
    BaseUrl = "https://api.signal.apollodeploy.com",
    TimeoutMs = 15_000,
});

var api = client.Emails;
```

## Configuration and reliability

The generated `HttpClient` transport supports cancellation tokens, bounded timeouts, exponential-backoff retries, `Retry-After` handling, default headers, and structured `SdkException` values. Unsafe requests are not retried unless they are explicitly idempotent or unsafe retries are enabled.

```csharp
var client = new ApolloSignalApiClient(new ApolloSignalApiClientConfig
{
    TimeoutMs = 30_000,
    MaxRetries = 3,
    DefaultHeaders = new() { ["X-Application"] = "my-service" },
});
```
